# Security

Security problems should not be reported in public issues. Use the **Report a vulnerability** button in the
**Security** tab of this repository: the report stays private until a fix is published.

Fixes are released for the latest published version only.

---

I problemi di sicurezza non vanno segnalati nelle issues pubbliche. Si usa il pulsante **Report a vulnerability**
nella scheda **Security** di questo repository: la segnalazione resta privata finché la correzione non è pubblicata.

Le correzioni riguardano solo l'ultima versione pubblicata.
